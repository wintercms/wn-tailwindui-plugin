Winter core — colour token map

Every colour core hardcodes today, mapped onto the design system scale you've already approved. The goal is that no colour is defined anywhere except this map — so dark mode and theming become redefinitions rather than a hunt.

Why not simply de-duplicate? Core's 193 values aren't mostly accidental variants — collapsing only what's imperceptible still leaves 123 of them. A small palette has to be chosen, not derived. So this maps onto the design system's 6 families × 10 steps instead. That is a real visual change for some elements, shown per token below.
